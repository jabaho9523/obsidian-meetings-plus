Documentation and positioning release — no functional code changes.

**What changed**

- Rewritten README: the calendar → pre-filled meeting note flow is now readable in about ten seconds, with the two key screenshots up top instead of buried at the bottom.
- New "Coming from Notion?" section — attendees land as `[[wikilinks]]` in plain local markdown, so meeting notes are linked the way Notion relations are, without the database or the lock-in.
- Plugin directory description updated to match.

**Recurring events**

The recurrence rework that landed across 0.5.0–0.5.2 is confirmed working by the reporter of
[#7](https://github.com/jabaho9523/obsidian-meetings-plus/issues/7) (iCloud recurring events not appearing). If you
were on an older version and had recurring events go missing, updating should fix it — and if it doesn't, please open
an issue with a sanitized ICS snippet.

**Upgrading**

Nothing to do. Settings, calendars, and templates carry over untouched.
