**Fix: daily notes now use your template**

When Meetings Plus created a daily note, for today's meeting list or for a meeting added to a daily note, it could create an empty note instead of using your Daily notes template. It now creates daily notes the same way Daily notes does, with your folder, date format and template, and it supports Periodic Notes as well. If creating from the template fails, Meetings Plus tells you instead of creating an empty note. Without Daily notes or Periodic Notes enabled, it still creates a plain `YYYY-MM-DD.md` in the vault root, as before.

With **Run Templater on new notes** on, Templater now also processes a daily note that Meetings Plus creates, right after creation and before any meetings are added.

Thanks @jarno-lernou-skyline for the fix ([#49](https://github.com/jabaho9523/obsidian-meetings-plus/pull/49)).
